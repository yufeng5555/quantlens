# Public scope, privacy and data review

Reviewed on 2026-09-28. Intended history: a fresh, reviewed snapshot only. The private repository's `.git` directory and original commit history are excluded.

The proposed snapshot omits external video links. Course attribution and the hosted demonstration link remain, so this is a portfolio release rather than an anonymous release. Before any publication, both author and committer metadata must use the intended public GitHub handle and GitHub-provided `noreply` email. Only the exact reviewed file allowlist and hashes may enter a new publication repository; `.gitignore` alone is not an upload boundary. Local preparation, audit records, generated runtime state and the private source repository must stay outside that repository.

Included: application/schema source needed for the local demo, pinned dependency declarations/locks, synthetic CSVs and generator, selected original tests, local-only launch/setup/example scripts, new project documentation, and a newly generated synthetic example report. Excluded: production state/databases/backups/configuration, Fly deployment/recovery files, credentials, user uploads, raw feedback, course evidence/materials, professor mail/recommendation records, vendor/real market CSVs, caches and installed dependencies.

A local pattern scan checks credential prefixes, private-key blocks, credential-bearing URLs, literal credential assignments, email-like strings and personal filesystem paths. Three email-like matches in the initial candidate were reviewed: a generic university sign-in placeholder, a public service default sender address, and a synthetic test address. None identifies an actual user's inbox or a credential. No credential-token/private-key/personal-path match was found in the initial candidate. The final clean snapshot is scanned again after example generation. Pattern scanning is a bounded check, not a proof that arbitrary personal information cannot occur.

The original private history also received a bounded scan; it contains email/path/credential-like matches in deployment documentation and tests. Those originals and their history are not proposed for publication. Secret-like values are not printed or stored in public reports. Source status and hashes are checked before/after preparation to show that original files remain intact.

Synthetic data is generated by the included seeded model, using NumPy/pandas and symbolic instrument labels. The values do not derive from real ETF history. Only these fictitious fixtures are distributed. The private project's market bundle refers to an upstream CC BY data publication, but no real market values or its historical dataset are included, so redistribution of that dataset is not being authorized by this release. User uploads remain local and ignored.

Installed Python package metadata/license files and npm lockfile license metadata are reviewed separately. Dependencies are installed from their upstream registries; their implementation code, binaries and license files are not vendored into the proposed source snapshot. No separate copied third-party code source was identified from file headers/imports in the included project code; this does not establish a complete historical authorship chain. The project owner confirmed release rights for this personal course project and the public copyright identifier `yufeng5555`.
