# Third-party dependencies and data

Review date: 2026-09-28. This source snapshot does not vendor installed Python/npm code or binaries. Dependencies are obtained separately from upstream registries through pinned, integrity-bearing locks. Their own licenses and notices remain applicable; the eventual top-level project license does not replace those terms.

`dependency-licenses.json` records 43 Python runtime/test packages (excluding the pip installer) and 68 npm lock entries, including optional platform packages. Python license classifiers/expressions and installed license files were examined; npm lock license metadata had no unspecified entry. Main components include pandas/NumPy (BSD), FastAPI (MIT), Starlette (BSD), Jinja2 (BSD), cryptography (Apache/BSD), exchange-calendars (Apache), Next.js/React/js-yaml (MIT). Transitive dependencies include MPL-licensed certifi and PSF-licensed typing extensions. No incompatible vendored code was identified; review the actual upstream notices if redistributing an environment or binary bundle later.

A file-header/import review identified no separately vendored third-party application implementation. AI assistance is described in CONTRIBUTIONS.md; a code review alone cannot establish exhaustive historical authorship. Project copyright attribution is recorded in LICENSE; it does not replace the upstream dependency terms.

Only the project's seeded synthetic fixtures are distributed. No real market CSV, third-party dataset archive, chart taken from courseware, instructor slide, external logo, or user-uploaded dataset is included. Real-data licensing and total-return assertions from the private deployment do not travel into this demonstration.

The candidate updates security-affected dependencies while retaining NumPy 2.2.1 and pandas 2.2.3 and preserving every worker algorithm file. Final audits reported zero known vulnerabilities; that is a time-bounded advisory database result, not a security guarantee. References for the initial web findings include [Next.js advisory](https://github.com/vercel/next.js/security/advisories/GHSA-2xp9-vwfh-vxw4), [js-yaml advisory](https://github.com/nodeca/js-yaml/security/advisories/GHSA-pm4m-ph32-ghv5), and [PostCSS advisory](https://github.com/postcss/postcss/security/advisories/GHSA-fxqj-rqcc-2cmp).
